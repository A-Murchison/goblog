Welcome to **goblog**

A static site generator written entirely in Go that converts Markdown files into a fast, clean static HTML blog, ready to deploy on GitHub Pages.

## How It Works

1. Write your blog posts as Markdown files in the `posts/` directory
2. Run `go run main.go build`
3. The `public/` directory is populated with static HTML
4. Push to `main` - GitHub Actions deploys to GitHub Pages automatically

## Why Go?

Go compiles to a single binary, is fast, and has an excellent standard library for templating and file I/O.

## Markdown Features

goblog uses [gomarkdown](https://github.com/gomarkdown/markdown) to parse Markdown.

It supports:

- **Bold** and _italic_ text
- `inline code` and fenced code blocks
- Headings, lists, and blockquotes
- Links and images
- Tables and automatic heading IDs

## Getting Started

Clone the repo and run:

```bash
git clone https://github.com/A-Murchison/goblog
cd goblog
go run main.go build
```

Your site will be in the `public/` directory.

Preview it locally:

```bash
go run main.go serve
```

This builds then serves the page. Click [http://localhost:8080](http://localhost:8080) to see your blog.
